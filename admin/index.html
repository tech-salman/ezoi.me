    Security note (read this)

    This is a static-only console — there is no server. The login runs entirely in your browser (PBKDF2 of your password), and the password hash is visible in admin.js. That means this gate is obfuscation, not real authentication: anyone who can fetch /admin/ can attempt the password offline.

    What IS real protection here: (1) the GitHub token lives only in this tab's memory and is sent only to api.github.com; (2) a strict CSP blocks injected scripts from exfiltrating that token; (3) a 30-min idle timeout and a 5-attempt / 15-min lockout slow casual guessing. For genuine protection, put a real gate in front of /admin/ at the edge (see admin/SECURITY.md).
