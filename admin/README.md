# ezoi.me Admin Console

A static-only browser console for editing ezoi.me content directly.

- `index.html` — login + dashboard
- `admin.js` — auth (PBKDF2), GitHub API client, editor, blog generator, deploy
- `admin.css` — dashboard theme
- `SECURITY.md` — security model and recommendations

Open at `https://ezoi.me/admin/`. Login: username `admin`, password as configured.
See `SECURITY.md` for the honest security model (static-only, no server).
